# CLAUDE.md

This is the Garsdale Cottages website - a static site for three holiday
cottages in Garsdale, in the Yorkshire Dales. Content lives in markdown
(`properties/`, `pages/`, `guide-pages/`, `locations/`) and is built with
Eleventy via the Chobble Template (see README.md).

## Writing or editing site copy

**Read `AGENTS.md` before touching any page copy.** It contains the site's
voice and tone guide, and - more importantly - the SEO hard rules: a rewrite
must never reduce a page's keyword coverage or word count, and headings,
meta fields, link text and first paragraphs keep their keywords no matter
what the voice would prefer. Those rules override everything else in the
guide.
